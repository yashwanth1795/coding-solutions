## Problem

### Coding Problem

Listen

You are given a character in the variable `name`.
There is a special rule in Chef town - You will get special treatment if your name is `C` or `A`.

Output the following:

- True if the name is A or C
- False otherwise

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-10T14:24:01.098Z  

```py
name = 'D'
# Update your code below this line
if (name=="A" or name=="C"):
    print("True")
else:
    print("False")

```
