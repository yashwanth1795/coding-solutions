## Problem

### Find the Area of any rectangle

Listen

Write a program that performs the following:

- Declare two integer variables: length and width.
- Accept two integer inputs from the user: one for length and one for width.
- Compute the area of the rectangle using the formula: $~~~~~~~~~~~~~~~~~~~~area=length \times width$
- Store the result in a variable named area.
- Output the result to the console in the format: "Area of the rectangle is: ".
### Sample 1:
Input
Output

```
10
23
```

```
Area of the rectangle is: 230
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-13T09:13:39.867Z

# Update your code below this line
lenght=int(input())
width=int(input())
z=lenght*width
print("Area of the rectangle is:",z)
