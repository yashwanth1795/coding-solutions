## Problem

### Cubes and Squares

Listen

Write a program which does the following:

- Accept a user input and assign it to a variable a.
- Declare 2 variables square and cube - compute and assign the square and cube of a in them respectively.
- Print values of square and cube on separate lines as per the sample output below.
- Note Square of an integer N = N x N Cube of an integer N = N x N x N
### Sample 1:
Input
Output

```
3
```

```
Square is: 9
Cube is: 27
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-13T09:14:33.113Z  

```py
# Update your code below this line
n=int(input())
print("Square is:",n*n)
print("Cube is:",n*n*n)
```
