## Problem

### Checking the type of variables

Listen

You can check the type of any variable or value by using the type function.

```
a = 5
print(type(a))

```

The above code gives <class 'int'> as the output as the variable $a$ is of type $int$.

### Task

You are given some variables in the code editor. Print the types of all these variables in separate lines.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-10T14:04:45.680Z  

```py
a = 3
b = 5.8
c = 'hello'
d = True
print(type(a))
print(type(b))
print(type(c))
print(type(d))
```
